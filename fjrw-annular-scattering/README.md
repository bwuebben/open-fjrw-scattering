# Annular scattering in quartic open FJRW theory

The manuscript previously posted here (August 2026) is withdrawn for
revision. Its final section claimed an annular cotangent correspondence for
the quartic descendent potentials; that correspondence is not proved.

A revised manuscript, restricted to the annular affine structure, the
scattering diagram and its comparison with the Gross--Kelly--Tessler
wall-crossing group, will be posted here.
